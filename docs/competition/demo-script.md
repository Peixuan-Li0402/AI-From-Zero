# 5 分钟演示脚本

## 0:00 - 0:40 项目问题

AI 初学者读论文时最大困难不是没有资料，而是不知道术语从哪里来、论文之间怎么接、下一步该读什么。

AI-From-Zero 的目标是把论文阅读变成一个可持续学习闭环。

## 0:40 - 2:20 一键论文学习

1. 打开首页。
2. 点击“Transformer 经典论文”演示案例。
3. 展示论文载入动画、术语高亮和术语边栏。
4. 点击 Transformer 或 Self-Attention，展示双语解释、前置概念和经典论文。

## 2:20 - 3:20 学习路径与下一篇论文

1. 展示 AI 学习舱中的下一篇推荐论文。
2. 点击“开始学习”，证明系统能把推荐论文载入阅读器。
3. 说明不是让用户自己去找论文，而是给链接、PDF 或摘要导读。

## 3:20 - 4:20 QQ / 微信 / OpenClaw 连接

1. 运行 `python tools/openclaw_ai_from_zero.py message "解释 Transformer"`。
2. 展示返回的术语解释。
3. 运行 `python tools/openclaw_ai_from_zero.py integrations`，展示微信和 QQ Webhook 配置状态。

## 4:20 - 5:00 总结价值

项目不是简单 PDF 摘要器，而是服务初学者的 AI 学习驾驶舱：读论文、懂术语、找下一篇、持续沉淀学习画像。
